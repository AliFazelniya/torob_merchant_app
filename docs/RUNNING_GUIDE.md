# راهنمای اجرای پروژه اپلیکیشن فروشندگان ترب (Running Guide)

این راهنما مراحل گام‌به‌گام راه‌اندازی و اجرای سرور بک‌اند، پنل وب مدیریت، و اپلیکیشن اندروید فروشندگان را توضیح می‌دهد.

---

## ۱. پیش‌نیازها

- **سیستم‌عامل:** لینوکس، مک یا ویندوز
- **پایتون:** نسخه 3.10 یا بالاتر
- **جاوا و اندروید:** JDK 17 یا بالاتر و Android Studio (یا Android SDK Command-line Tools)

---

## ۲. راه‌اندازی و اجرای سرور بک‌اند و پنل مدیریت

### گام اول: نصب وابستگی‌های پایتون
در پوشه اصلی پروژه یا ترمینال، دستور زیر را اجرا کنید:
```bash
pip install -r chatapp/backend/requirements.txt
```

### گام دوم: تنظیم متغیرهای محیطی (اختیاری)
می‌توانید یک فایل `.env` در پوشه `chatapp/backend/` بر اساس نمونه `.env.example` بسازید:
```bash
cp chatapp/.env.example chatapp/backend/.env
```
*(در حالت پیش‌فرض، مقادیر اولیه برای اجرای خودکار و تست‌های محلی بدون نیاز به کلیدهای جانبی آماده هستند).*

### گام سوم: راه‌اندازی سرور بک‌اند
وارد پوشه بک‌اند شده و سرور Uvicorn را اجرا نمایید:
```bash
cd chatapp/backend
python3 -m uvicorn main:app --host 0.0.0.0 --port 8080 --reload
```

پس از اجرا:
- **داشبورد مدیریت تحت وب:** در مرورگر به آدرس [http://localhost:8080/admin](http://localhost:8080/admin) مراجعه فرمایید.
- **مستندات تعاملی Swagger API:** در آدرس [http://localhost:8080/docs](http://localhost:8080/docs) در دسترس است.
- **بررسی سلامت سیستم:** در آدرس [http://localhost:8080/api/health](http://localhost:8080/api/health).

---

## ۳. اجرای تست‌های خودکار

برای اجرای کلیه تست‌های اعتبارسنجی ورود با پیامک، استعلام‌ها، همگام‌سازی آفلاین، زمان‌بندی و لاگ‌های پوش‌نوتیفیکیشن:
```bash
python3 -m pytest chatapp/tests/ -v
```

---

## ۴. اجرای اپلیکیشن اندروید (Android Studio / Gradle)

### اجرای در Android Studio:
1. برنامه **Android Studio** را باز کنید.
2. گزینه **Open** را انتخاب کرده و پوشه `chatapp/android` را انتخاب فرمایید.
3. اجازه دهید Gradle فرآیند Sync و دانلود کتابخانه‌ها را تکمیل نماید.
4. یک شبیه‌ساز (Emulator با API 26 تا 34) یا یک گوشی واقعی با قابلیت USB Debugging متصل کنید.
5. دکمه سبز رنگ **Run ('app')** را بزنید.

### آدرس اتصال در شبیه‌ساز و گوشی واقعی:
- **در Android Emulator:** به طور پیش‌فرض آدرس سرور روی `http://10.0.2.2:8080/api/` تنظیم شده است و مستقیماً به هاست لوکال متصل می‌شود.
- **در گوشی واقعی:** در صفحه تنظیمات برنامه (Settings)، آدرس سرور را به آی‌پی محلی سیستم خود در شبکه وای‌فای (مثلاً `http://192.168.1.105:8080/api/`) تغییر دهید.

### سناریوی آزمایشی ورود و ثبت استعلام:
1. در صفحه ورود اپلیکیشن، شماره `09123456789` را وارد کنید.
2. کد تایید دمو `12345` را وارد کرده و وارد شوید.
3. در پنل ادمین ([http://localhost:8080/admin](http://localhost:8080/admin)) از تب **شبیه‌ساز ارسال استعلام**، یک استعلام تستی ارسال کنید.
4. اعلان استعلام بلافاصله در اپلیکیشن ظاهر می‌شود. با لمس آن، صفحه جزئیات کالا باز شده و می‌توانید با لمس چیپ‌های قیمتی (+۵۰ هزار تومان) یا سوئیچ موجودی، پاسخ خود را به صورت آنی ثبت کنید.
5. در صورت قطع بودن اینترنت، پاسخ با برچسب زرد‌رنگ «ذخیره در گوشی» روی دستگاه ذخیره شده و پس از برقراری اینترنت به صورت خودکار با سرور همگام می‌شود.
