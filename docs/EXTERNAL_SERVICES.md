# فهرست سرویس‌های جانبی و کلیدهای مورد نیاز (External Services & Fallbacks)

این سند تمامی سرویس‌های خارجی، کلیدهای دسترسی (API Keys)، و رفتارهای جایگزین (Fallback / Mock) پیاده‌سازی‌شده در سیستم را تشریح می‌کند.

---

## ۱. سرویس پوش‌نوتیفیکیشن فایربیس (Firebase Cloud Messaging - FCM HTTP v1)

| ویژگی | توضیحات |
| :--- | :--- |
| **هدف** | مخابره آنی استعلام جدید (ثانیه ۰)، یادآوری (دقیقه ۵)، و انقضا (دقیقه ۱۰) به گوشی اندروید حتی در شرایط صفحه خاموش و Doze Mode. |
| **نوع اعتبارسنجی** | استاندارد Google OAuth2 با استفاده از Service Account JSON |
| **کلیدهای مورد نیاز** | `FCM_PROJECT_ID` و فایل `FCM_SERVICE_ACCOUNT_FILE` در سرور، و `google-services.json` در کلاینت اندروید. |
| **رفتار جایگزین (Fallback / Dev Mode)** | در صورتی که کاربر هنوز فایل کلید فایربیس را تنظیم نکرده باشد، سیستم بدون خطا به حالت **Simulated Mode** سوئیچ می‌کند. تمامی درخواست‌های ارسال نوتیفیکیشن با پیلود کامل High-Priority در جدول `push_audit_logs` ثبت شده و در داشبورد وب ادمین به صورت بلادرنگ قابل مشاهده و تست خواهند بود. همچنین برنامه اندروید دارای شناسه و قابلیت اتصال پایدار است. |

## ۲. سامانه پیامک احراز هویت (SMS OTP Gateway)

| ویژگی | توضیحات |
| :--- | :--- |
| **هدف** | ارسال کد تایید ۵ رقمی ورود فروشندگان به شماره همراه. |
| **سرویس‌های پشتیبانی‌شده** | کاوه‌نگار (Kavenegar)، ایده پردازان (Sms.ir)، و حالت ماک داخلی. |
| **کلیدهای مورد نیاز** | `SMS_PROVIDER` و `SMS_API_KEY` در فایل `.env`. |
| **رفتار جایگزین (Fallback / Dev Mode)** | در حالت پیش‌فرض (`SMS_PROVIDER="mock"` یا در صورت خالی بودن کلید)، کد تایید به صورت خودکار تولید و در پاسخ API تحت فیلد `demo_otp` برگردانده می‌شود. علاوه بر این، کد پیش‌فرض `12345` همواره در محیط تست به عنوان کد معتبر پذیرفته می‌شود تا فرآیند تست بدون نیاز به شارژ درگاه پیامکی انجام شود. |

## ۳. مسیریابی و نقشه‌های ناوبری (Turn-by-Turn Navigation)

| ویژگی | توضیحات |
| :--- | :--- |
| **هدف** | هدایت خریدار به آدرس فیزیکی فروشگاه در تهران. |
| **سرویس‌های پشتیبانی‌شده** | نشان (Neshan)، بلد (Balad)، و گوگل مپ (Google Maps). |
| **کلیدهای مورد نیاز** | **بدون نیاز به کلید (Zero API Key)** — مستقیماً از URI Schemeهای استاندارد اپلیکیشن‌ها (`nshn:`, `geo:`, `https://maps.google.com`) استفاده می‌شود. |
